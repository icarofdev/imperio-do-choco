CONFIGURAÇÃO LOCAL DO BANCO

1. Crie o banco imperio_do_choco no MySQL.
2. Copie .env.example para .env.
3. Configure DB_HOST, DB_PORT, DB_NAME, DB_USER e DB_PASS.
4. Execute:
   C:\xampp\php\php.exe database\migrate.php
5. Para criar um administrador sem publicar credenciais, defina temporariamente
   ADMIN_NAME, ADMIN_EMAIL e ADMIN_PASSWORD no terminal e execute:
   C:\xampp\php\php.exe scripts\criar-admin.php
6. Remova essas três variáveis do terminal após o comando.

Não há e-mail, senha ou hash administrativo padrão no repositório.
